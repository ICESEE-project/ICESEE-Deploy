# Contributing

Report integration, deployment, and manuscript issues in
[ICESEE-Deploy Issues](https://github.com/ICESEE-project/ICESEE-Deploy/issues).
For platform behavior use [CryoStack Issues](https://github.com/ICESEE-project/CryoStack/issues).
Include source/submodule revisions, reproduction steps, expected behavior,
and relevant logs with credentials removed.

Fork the repository and open a scoped pull request against `main`, explaining
what changed and how it was verified. Component code changes belong upstream;
gitlink updates here must reference publicly available commits. Follow the
offline-check instructions in README.md and run relevant component tests when
changing behavior. Scientific workflows require their own environment and live
validation. Paper changes must retain accurate authorship, funding, citations,
and disclosures, and pass the existing draft-PDF workflow.
